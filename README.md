# 高性价比人生 · 人生闯关

把《高性价比人生指南》的 690 条建议，压成 10 个生活路口。

每个路口三个选项。选完立刻告诉你：这一下花掉了什么、换回了什么、书里怎么说、出自第几节第几条。

三条命脉：**❤️ 命 / 💰 钱 / 🧭 自由**。归零就是三种坏结局——早死、破产、被告席。约 10 分钟一局。

## 玩

| 方式 | 怎么做 |
| --- | --- |
| 网页版 | 打开 `index.html`，手机上也能开 |
| 微信小游戏 | 微信开发者工具导入本仓库根目录，项目类型选**小游戏** |
| Canvas 预览 | 打开 `preview.html`，不用装开发者工具就能看小游戏长什么样 |

玩到一半关掉，下次打开会接着上次那一关。网页版和 Canvas 预览都能用键盘：`1` `2` `3` 选选项，回车点底部按钮（小游戏没有键盘，只有触屏）。

## 分镜条

每个路口顶上有一条会动的带子：本关地点的样子 + 没选之前每隔几秒“说一句”的剪影，选完就静下来。

它**不吃任何图片**，全是 canvas 现画的，零资源、零许可麻烦，包体也不涨。

- 地点三种：`indoor`（屋里）、`corridor`（楼道 / 走廊）、`street`（街边）
- 光四种：`window`、`lamp`、`screen`、`sky`
- 道具从一个固定名单里挑，名单在 `scene.js` 的 `PROPS`

换景就在 `levels.js` 里改那一关的 `stage` 一行：

    stage: { where: "indoor", light: "window", tint: "#d9a441", props: ["carton", "box", "door"] },

道具名写错 `check.mjs` 会拦下来。带子只吃剩下的空间：小屏手机上正文厚，带子就矮；
大屏上给足（最高 206px）。**正文永远不需要为了它滑动。**

## 改关卡

**只改 `levels.js`**，网页版和小游戏版一起变。改完跑一次自检：

```
node check.mjs
```

它查字段、选项数，核对每关正好一个正确选项，并算一遍最好和最坏两条路能不能走完；顺带校验两个 JSON 配置合法（JSON 写坏时，微信开发者工具只会报「game.json not found」，很难查），以及每关 `stage` 里的地点、光、道具名字有没有写错。

`engine.js` 的判断逻辑另有测试，改完也跑一下：

```
node --test
```

## 文件

| 文件 | 作用 |
| --- | --- |
| `levels.js` | **唯一数据源**：10 关、场景、台词、数值、出处 |
| `engine.js` | 纯逻辑：加减分、判定坏结局、算段位、验证存档、拼分享文案。不碰 DOM 也不碰 Canvas |
| `engine.test.mjs` | 上面这些逻辑的测试（`node --test`） |
| `scene.js` | 分镜条：把每关的 `stage` 画成那条会动的带子 + 人物剪影。只画 canvas |
| `scene.test.mjs` | 分镜条的测试：每关都画得出、坐标不出 NaN、save/restore 不串 |
| `platform.js` | 平台适配：画布、输入（触屏 + 键盘）、读存档、分享、开外链 |
| `index.html` `web.js` `style.css` | 网页版（DOM 渲染） |
| `preview.html` `main.js` `ui.js` | Canvas 渲染层，也是小游戏的界面 |
| `game.js` `game.json` `project.config.json` | 微信小游戏入口和配置 |
| `check.mjs` | 数据与配置自检 |

存档写在 `localStorage`（小游戏里是 `wx.setStorageSync`）的 `htlb.save` 一个键上，读回来会当成不可信输入校验一遍；走完一局即清掉。

小游戏里**没有 DOM 和 CSS**，所有文字、卡片、按钮都在 `ui.js` 里用 Canvas 手画。触屏事件、打开外链的方式收在 `platform.js`——小游戏打不开外链，所以「翻原文」在小游戏里是复制链接，网页里才是新窗口。

分镜条在两边都跑，但方式不同：小游戏（和 Canvas 预览）挂在 `main.js` 的帧循环上，每帧只重画分镜条和 HUD，下面的卡片不重画；网页版只给 `index.html` 里那个 `<canvas id="band">` 开一个帧循环，DOM 一个字都不重画。离开闯关页就停掉循环，不白烧电；系统开了「减少动态效果」就只画一帧。
